# ComplyOn LLC — Marketing Site

The single-page marketing site for ComplyOn LLC, an independent compliance
and risk advisory practice. It is a static page: one hand-written HTML file
with inline CSS and no JavaScript framework.

## Requirements

- Node.js 20.19+ (developed on v22)
- npm

## Getting started

```bash
npm install
npm run dev
```

The dev server prints a local URL (http://localhost:5173 by default) and
reloads the page whenever you save.

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the Vite dev server with live reload. |
| `npm run build` | Build a static site into `dist/`. |
| `npm run preview` | Serve the built `dist/` locally to check it before deploying. |

## Layout

```
index.html        the entire site — markup and CSS in one file
reema-keen.jpg    founder portrait, referenced from the About section
vite.config.js    dev server port and build output settings
dist/             build output (generated, git-ignored)
```

**Edit `index.html` at the project root, not `dist/index.html`.** Everything
in `dist/` is regenerated by `npm run build` and any edits there are lost.

## How the page is organised

All CSS lives in one `<style>` block in the document head, grouped by
section with comment headers (`/* ---------- header ---------- */` and so
on). The markup below it follows the same order: header, hero, about,
services, experience, industries, engagements, FAQ, contact, footer.

Fonts (Cormorant Garamond and DM Sans) load from Google Fonts, so the page
needs network access to render with its intended typography. The favicon is
an inline SVG data URI in the head — there is no icon file.

## Responsive design

The base CSS is the desktop layout; nearly every media query is a
`max-width` override that adapts it downward. The breakpoints are tuned to
specific devices and carry comments explaining why, so read the comment
before changing a number. The exception is the `min-width: 861px` block,
which scales the header up for desktop while leaving the carefully fitted
640–860px band alone.

When changing the header height, update the `scroll-margin-top` in that same
block to match — it keeps the sticky header from covering the top of
whatever section a nav link jumps to.

## Deployment

`npm run build` produces a self-contained `dist/` directory that any static
host will serve — no server-side runtime required. The build inlines nothing
new; it rewrites the image reference to a content-hashed filename in
`dist/assets/` so it can be cached aggressively.

## Known limitation

The contact form posts to a `mailto:` address. Browser support for this is
inconsistent — several block the submission outright, and where it does work
it opens the visitor's email client rather than sending anything itself.
Moving to a form service or a small backend endpoint is worth considering if
the form needs to be dependable.
